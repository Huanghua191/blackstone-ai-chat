# 个人项目合集

两个基于 DeepSeek API 的 AI 互动应用。

---

## 《黑石密码》AI 聊天应用

基于小说世界观。Flask 后端，原生前端，SQLite 存对话。

**功能：**
- AI 角色扮演，贴合原著
- 多轮对话记忆
- 多会话管理
- SQLite 持久化存储

**文件：**
- `app.py` 后端
- `blackstone_game.html` 文字冒险游戏

---

## 《玫瑰与蜂蜜》酒馆经营游戏

奇幻题材。三天内完成从黑石密码框架的题材切换。

**功能：**
- 3位事件线客人 + 3位散客
- 数值系统：铜币、声望、配方、友谊值
- 关系记忆：熟客不会失忆
- 代答系统
- 存档系统（3手动+1自动）
- 气氛组与离场机制

**文件：**
- `tavern-game/tavern_game.py` 主程序
